Check whether your WordPress website is ready to launch with a simple site-readiness checklist.

== Description ==

Sharmin Site Readiness Review helps WordPress developers and site owners review important website settings before launching a site.

The plugin provides a simple dashboard that checks common site-readiness items and categorizes each result as Passed, Warning, or Failed.

Current checks include:

* Search engine visibility
* WordPress debug mode
* HTTPS / SSL
* Site title and tagline
* Site icon
* Permalink structure
* Privacy policy configuration
* Homepage configuration

The dashboard also provides a site-readiness score and allows results to be filtered by Passed, Warning, or Failed status.

Sharmin Site Readiness Review does not modify your website settings. It only reads existing WordPress configuration and reports the results.

== Installation ==

1. Upload the Sharmin Site Readiness Review plugin to WordPress.
2. Activate the plugin through the Plugins screen.
3. Open Site Readiness Review from the WordPress admin menu.
4. Review the site-readiness results.

== Frequently Asked Questions ==

= Does Sharmin Site Readiness Review change my website settings? =

No. Sharmin Site Readiness Review is read-only. It checks existing WordPress settings and reports potential site-readiness issues without modifying them.

= Does every warning need to be fixed? =

No. Some settings depend on the type of website being built. For example, a blog may intentionally display recent posts on its homepage.

= Why does my site receive a warning when search engine indexing is disabled? =

Search engine indexing is commonly disabled while a website is under development. Before launching a public website, you may want to allow search engines to index it.
